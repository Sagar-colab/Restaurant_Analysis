
# 🍽️ Restaurant Analysis Using SQL

## 📌 Project Overview

This project focuses on designing and implementing a comprehensive SQL based restaurant analysis system using a relational database model. The objective is to analyze consumer behavior, dining preferences and restaurant performance to generate actionable business insights that support data driven decision making.

## 🗄️ Database Design

The database was created from scratch and structured using multiple related tables to ensure data integrity and scalability.

### Tables Included

* **Consumers** – Demographic, lifestyle and budget details
* **Consumer_Preferences** – Preferred cuisines for each consumer
* **Restaurants** – Restaurant details, pricing, facilities and location
* **Restaurant_Cuisines** – Cuisine types offered by restaurants
* **Ratings** – Overall, food and service ratings given by consumers

Primary and foreign keys were used to establish strong relationships between entities.

## 🛠️ Skills & SQL Concepts Used

* Relational database design
* Complex JOIN operations
* WHERE, GROUP BY and HAVING clauses
* Subqueries and derived tables
* Common Table Expressions (CTEs)
* Window functions (RANK, DENSE_RANK, ROW_NUMBER, LEAD)
* Views for reusable analysis
* Stored procedures for parameterized queries

## 🔍 Key Analysis Performed

* Identified consumer segments based on age, occupation, budget and preferences
* Analyzed restaurant performance using overall, food and service ratings
* Evaluated cuisine popularity and customer satisfaction trends
* Compared regional and city wise restaurant performance
* Ranked restaurants and consumers using window functions
* Built views and procedures to support reusable and scalable analysis

## 📈 Business Insights

The analysis provided insights into:

* Consumer dining behavior and cuisine preferences
* High performing restaurants and cuisines
* Rating patterns across demographics and locations
* Budget based consumer segmentation
* Restaurant performance benchmarking

## 🚀 Outcome

This project demonstrates strong proficiency in SQL, relational database modeling and advanced querying techniques. It showcases the ability to translate structured data into meaningful insights using analytical depth, accuracy and business focused logic.
